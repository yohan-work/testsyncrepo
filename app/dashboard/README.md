# 대시보드 페이지

## 개요
이 페이지는 판매량, 방문자 수, 전환율을 표시하는 간단한 대시보드를 제공합니다.

## 기능
1. **판매량**: 최근 30일간의 판매량 그래프
2. **방문자 수**: 최근 30일간의 방문자 수
3. **전환율**: 전환율 (%)

## 데이터 시각화
- `components/ui` 디렉토리에서 제공하는 컴포넌트를 사용하여 가상 데이터로 간단한 그래프와 숫자를 표시합니다.

## 의존성
- Tailwind CSS: 페이지의 스타일링을 위해 사용됩니다.
- React, Next.js: 페이지 구현에 필수적입니다.

## 설치된 패키지
- @prisma/client (Mock Data): 실제 데이터베이스 액세스를 위한 가상 클라이언트

## 제약 조건
1. `"use client"` 지시자를 사용하여 React hooks와 인터랙티브 요소를 구현합니다.
2. `components/ui` 디렉토리의 컴포넌트만 사용합니다.

## 데이터 표시
- 판매량, 방문자 수, 전환율에 대한 가상 데이터가 포함되어 있습니다.

## 개발 가이드
1. `app/dashboard/page.tsx` 파일을 수정하여 대시보드 페이지를 구현합니다.
2. 가상 데이터는 `components/ui` 디렉토리에서 제공하는 컴포넌트로 표시됩니다.
3. Tailwind CSS 스타일링을 적용하여 페이지의 전체적인 스타일을 만듭니다.

## 검증
1. 페이지가 성공적으로 렌더링되는지 확인합니다.
2. 3개의 위젯이 올바르게 표시되는지 확인합니다.
3. Tailwind CSS 스타일링이 적용된 지 확인합니다.
4. `components/ui` 디렉토리의 컴포넌트가 올바르게 사용되었는지 확인합니다.
